# Datos

El archivo `CriticalData_Sepsis.csv` (10.000 registros, 68 variables) fue entregado al equipo por una entidad del sector salud en el marco de una iniciativa con la Universidad Autónoma de Occidente. No se incluye en el repositorio porque, aunque no contiene identificadores directos, no se cuenta con autorización para redistribuirlo ni con documentación de su proceso de anonimización, y en Colombia los datos de salud se consideran datos sensibles (Ley 1581 de 2012).
